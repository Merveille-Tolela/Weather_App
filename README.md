# 🌦️ Weather Info App

A simple Django web application that fetches and displays real-time weather data for any city using the OpenWeatherMap API and Python’s `urllib` library.

## 🛠️ Tech Stack

- **Backend**: Django
- **API**: OpenWeatherMap
- **HTTP Client**: `urllib`
- **Frontend**: Django Templates (HTML)

## 🚀 Features

- Enter a city name to get:
  - Country code
  - Coordinates (longitude & latitude)
  - Temperature (in Kelvin)
  - Pressure
  - Humidity
